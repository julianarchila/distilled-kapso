# distilled-kapso

An Effect-native [Kapso](https://kapso.ai) (WhatsApp Business Platform) SDK, built the way
[distilled](https://distilled.cloud) builds its SDKs: generated from Kapso's OpenAPI spec by
distilled's own generator, with hand-written credentials, protocol, errors and webhooks.

- [`packages/kapso`](packages/kapso): the SDK, `distilled-kapso`. Start with its README.
- [`AGENTS.md`](AGENTS.md): how this repo works and how it differs from the distilled monorepo.
